# ☕ Учебная конфигурация «Кофе и код» (1С:Предприятие 8.3)

Учебный пет-проект по разработке конфигурации с нуля на платформе **«1С:Предприятие 8.3»** для автоматизации оперативного учета, складских операций и контроля остатков товаров в кофейне/магазине.

---

## 📋 Что делает проект

Конфигурация реализует базовый контур автоматизации торговли и складского учета:
* **Ведение НСИ (Нормативно-справочной информации):** хранение сведений о номенклатуре, ценах, единице измерения, поставщиках и складах.
* **Учет хозяйственных операций:** фиксация поступлений товаров от поставщиков и оптовых/розничных продаж с помощью специализированных документов.
* **Оперативный контроль остатков:** автоматическая проверка наличия достаточного количества товара на складе при проведении документов отгрузки с блокировкой проведения в случае дефицита (контроль отрицательных остатков).
* **Формирование аналитической отчетности:** сводный анализ движения и остатков товаров с использованием Системы компоновки данных (СКД).

---

## 💡 Почему проект полезен

* **Демонстрация архитектурного подхода в 1С:** проект показывает практическое применение базовых объектов метаданных (Справочники, Документы, Регистры накопления, Отчеты СКД) и логику связи между ними.
* **Готовый шаблон логики учета:** демонстрирует механизм проведения документов по регистрам накопления и алгоритмы автоматического расчета сумм при изменении количества или цены.
* **Практический кейс для портфолио:** служит наглядным подтверждением навыков конфигурирования и проектирования бизнес-процессов для позиции **Junior Аналитик / Разработчик 1С**.

## 🚀 Как приступить к работе с проектом

### Предварительные требования
* Установленная платформа **«1С:Предприятие 8.3»** (версия 8.3.18 и выше, подходит и Бесплатная учебная версия).

### Вариант 1: Загрузка готового файла конфигурации (`.cf`)
1. Склонируйте репозиторий или скачайте файл `CoffeeAndCode.cf` из этого репозитория.
2. Запустите 1С и создайте новую пустую информационную базу.
3. Откройте созданную базу в режиме **Конфигуратор**.
4. В верхнем меню выберите **Конфигурация → Загрузить конфигурацию из файла...** и укажите файл `CoffeeAndCode.cf`.
5. Нажмите **F7** (Обновить конфигурацию базы данных) и запустите режим «1С:Предприятие» (**Ctrl + F5**).

### Вариант 2: Загрузка из выгрузки в файлы (для анализа кода)
1. Выполните команду меню **Конфигурация → Загрузить конфигурацию из файлов...**
2. Укажите папку `src/` из данного репозитория.

## 🛠️ Архитектура метаданных

* **Подсистемы:** `УчетТоваров`, `Продажи`
* **Справочники:** `Номенклатура`, `Контрагенты`, `Склады`
* **Документы:** `ПоступлениеТоваров`, `РеализацияТоваров`
* **Регистры накопления:** `ОстаткиТоваров` (вид регистра: *Остатки*)
* **Отчеты:** `ОстаткиТоваровНаСкладах` (на базе СКД)
